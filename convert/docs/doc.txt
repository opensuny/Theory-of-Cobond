合并封面与正文，并修正书签
使用 cpdf 是最佳选择。它会在合并时自动将正文的书签页码，加上封面的页数，完成偏移

<?php
$cover = 'cover.pdf'; // 封面PDF路径
$main  = 'main.pdf';  // 正文PDF路径（带书签）
$output = 'merged.pdf';

// 使用cpdf合并，会自动处理书签偏移
$cmd = 'cpdf -merge ' . escapeshellarg($cover) . ' ' . escapeshellarg($main) . ' -o ' . escapeshellarg($output);
exec($cmd, $outputLines, $returnCode);

if ($returnCode === 0 && file_exists($output)) {
    echo "合并成功：{$output}\n";
} else {
    echo "合并失败，返回码：{$returnCode}\n";
    echo implode("\n", $outputLines);
}
?>

注意：cpdf 的 -merge 命令默认会保留并合并书签，页码会自动加上前面文档的页数。如果封面有特殊尺寸，可以添加 -scale-to-fit "210mm 297mm" 参数统一页面大小。

功能3：添加页码
使用 FPDI + TCPDF，可以灵活控制页码的位置、起始页和格式。

php
<?php
require_once 'vendor/autoload.php';

use setasign\Fpdi\Tcpdf\Fpdi;

$pdf = new Fpdi();
$pdf->setPrintHeader(false);
$pdf->setPrintFooter(false);

$pageCount = $pdf->setSourceFile('merged.pdf');
$bodyStartPage = 3; // 假设正文从合并后的第3页开始（封面2页）

for ($i = 1; $i <= $pageCount; $i++) {
    $pdf->AddPage();
    $tplId = $pdf->importPage($i);
    $pdf->useTemplate($tplId);

    // 封面和扉页不显示页码
    if ($i < $bodyStartPage) continue;

    $pageNum = $i - $bodyStartPage + 1;

    // 添加页码（居中，距底部15mm）
    $pdf->SetFont('cid0cs', '', 10); // 使用中文字体
    $pdf->SetTextColor(102, 102, 102);
    $pdf->SetXY(0, -15); // 负数表示从页面底部向上偏移
    $pdf->Cell(0, 10, $pageNum, 0, 0, 'C');
}

$pdf->Output('final_with_pagenum.pdf', 'F');
?>
中文字体配置：需要先注册中文字体文件（如 simsun.ttc 或 msyh.ttf），使用 TCPDF_FONTS::addTTFfont() 方法。

功能4：印刷版奇偶页边距偏移
使用 useTemplate() 方法的 $x 参数，可以控制每一页内容的水平偏移量。

php
$bleed = 5; // 装订边偏移量，单位mm

for ($i = 1; $i <= $pageCount; $i++) {
    $pdf->AddPage();
    $tplId = $pdf->importPage($i);

    // 奇数页向右偏移，偶数页向左偏移
    if ($i % 2 == 1) {
        $pdf->useTemplate($tplId, $bleed, 0); // 向右偏移
    } else {
        $pdf->useTemplate($tplId, -$bleed, 0); // 向左偏移
    }

    // 页码单独定位，不受偏移影响
    // ... 添加页码的代码 ...
}
前提：在Chrome打印HTML时，左右两侧需要预留足够的对称边距（例如20mm），确保偏移后内容不会被裁剪。
